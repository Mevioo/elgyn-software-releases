# ELGYN Software — distribution

Ce dépôt ne contient **que les installeurs Windows**. Le code source n'est pas
ici.

## Installer

Va sur la page [Releases](../../releases), télécharge le `.exe` le plus récent,
lance-le.

Windows affichera un avertissement SmartScreen au premier lancement :
l'exécutable n'est pas signé. « Informations complémentaires » puis
« Exécuter quand même ».

## Mises à jour

L'application vérifie cette page au démarrage et te prévient quand une version
plus récente existe. Rien n'est téléchargé ni installé automatiquement.

## Premier démarrage

Ouvre l'onglet **Réglages**. Il faut :

- une clé pour le moteur de texte — [OpenRouter](https://openrouter.ai/keys)
  propose des modèles gratuits, [Google AI Studio](https://aistudio.google.com/apikey)
  est nécessaire pour la retouche d'images ;
- un token [DOTB](https://dotb.io) (abonnement Boutique AI).

Ces clés sont les tiennes et restent sur ta machine, dans
`%APPDATA%\ELGYN Software\`.
